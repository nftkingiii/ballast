Ballast

Hash or curtail, hour by hour

Ballast buys a power price, a hashprice and a weather check from Telegraph, checks them against each other, and says RUN, CURTAIL or HOLD for each hour. When a check is missing it holds and names the check. It recommends only; no miner is switched.

    What each hour can say

    RUN
    Margin clears the throttle band ($8/MWh on the demo site).
    THROTTLE
    Margin is positive but thin, so run part of the fleet.
    CURTAIL
    Margin is below zero.
    HOLD
    An input is missing or conflicting. The plan names the check instead of guessing.

    What gets rejected

    • A stale answer
    • An answer for another node or market
    • An answer that disagrees with free public data beyond tolerance
    • Spend past the cap: later hours are held

    A wrong-market or wrong-interval answer is asked again, then read from the public archive and labelled public.
